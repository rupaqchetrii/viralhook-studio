🤖 ML Model Card & Architecture
📐 Model Architecture
  • 🏗 Dual-Tower: TF-IDF + Psycholinguistic
  • 📊 TF-IDF: 1–3 ngrams, 2000 features
  • 🧪 24 psycholinguistic features
  • 🔧 L1-regularized Logistic Regression
  • 📈 Isotonic calibration (probability)
  • ✅ 5-fold stratified cross-validation
📊 Performance Metrics
  • 🎯 Macro-F1: 0.9977
  • 📚 Dataset: TM-HIC (3,000 records)
  • 🏷 Classes: Low / Medium / High
  • 🧮 120 / 120 unit tests passing
  • ⚖ Margin Guard threshold: ΔP < 0.08
  • 🛡 "Dead-Heat" flag prevents bias
🛠 Tech Stack
  • ⚛ React 19 + Vite 8 (Frontend)
  • 🐍 FastAPI + Uvicorn (Backend)
  • 🗃 SQLite — Hook Library DB
  • 🔬 scikit-learn (ML pipeline)
  • 🎨 Tailwind CSS + Zustand
  • 📊 Recharts / Chart.js
🔍 Linter Rules Reference
🔴 RED — Auto-fixable
  • "in this video I will show you" → "Here is how to"
  • "hey guys" → (remove)
  • "subscribe for more" → (remove)
  • "today I want to talk about" → "This will change how you view"
🟡 YELLOW — Warnings
  • "secret hack" — overused
  • "you won't believe" — clickbait
  • "wait until the end" — audience drop-off risk
🟢 GREEN — Strength Signals
  • "stop doing/making" — pattern interrupt
  • "if you are/have" — direct address
  • Numbers + "mistakes/ways/steps" — specificity
